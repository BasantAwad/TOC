# Theory of Computation Exercises

A collection of Theory of Computation work covering formal models, language reasoning, and computational problem-solving exercises.

## Scope

The repository is organized as an academic reference for studying computational models and the relationships between languages, machines, grammars, and algorithms. Each exercise should be read together with its problem statement and any accompanying report or diagram.

## How to use

Clone the repository and open the exercise files in the order presented by the directory structure. Preserve the original problem statements when adding solutions so the reasoning remains easy to review.

## Technology

Theory of Computation, formal languages, automata, algorithmic reasoning, and academic documentation.
